# IranAPI Frontend

React/Vite client for IranAPI.

## Development

```sh
npm install
npm run dev
```

The dev server proxies API calls to `http://127.0.0.1:8000` by default. Override with:

```sh
VITE_DEV_PROXY_TARGET=http://127.0.0.1:8000 npm run dev
```

## Build

```sh
npm run build
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

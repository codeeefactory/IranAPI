# IranAPI Hub

a modern api marketplace platform with persian language support

## features

- comprehensive api catalog
- persian (farsi) interface
- dark/light theme
- api documentation
- pricing plans
- user authentication

## tech stack

- react 18 + typescript
- vite
- tailwindcss
- shadcn/ui components
- react router
- tanstack query

## setup

```bash
cd api-hub-express
npm install
npm run dev
```

## structure

```
api-hub-express/       # frontend react application
├── src/
│   ├── components/   # reusable components
│   ├── pages/        # route pages
│   ├── hooks/        # custom hooks
│   └── lib/          # utilities
└── public/           # static assets
```

## development

- dev server: `npm run dev`
- build: `npm run build`
- lint: `npm run lint`
